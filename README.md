## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set **Branch: main** and **Folder: / (root)**, then click **Save**.
4. GitHub will show the published address after deployment. The usual project URL is `https://aravinds-kannappan.github.io/Technical-Deep-Dive/`, but it is not live until Pages is enabled and deployed.

**Note:** This repository is currently **private**. GitHub Pages on private repositories requires an eligible GitHub plan. If the Pages options are unavailable, a repository visibility or plan change might be necessary. Verify that no sensitive materials are included before making the repository public. The uploaded CV is not part of this repository.

The homepage uses relative links, so all three guides work under one project-site URL without a JavaScript build or framework. `index.html` is the entry point. Open it locally in a browser to preview.
